# GitHub за 10 минут (для новичка)

Цель: сайт «Мотивация» по адресу `https://ЛОГИН.github.io/РЕПО/`, который сам пересобирается при каждом изменении.

## 1. Аккаунт и репозиторий (2 мин)
1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+ → New repository**. Имя, например, `motivaciya`. Тип **Public**. Ничего не добавляйте (без README). **Create repository**.

## 2. Загрузите проект (3 мин)
Установите Git (https://git-scm.com), откройте папку проекта в терминале и выполните:

- Windows: `upload-to-github.bat ЛОГИН motivaciya`
- macOS/Linux: `./upload-to-github.sh ЛОГИН motivaciya`

Git попросит войти в GitHub — войдите через браузер.

## 3. Включите Pages (1 мин)
В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Больше ничего выбирать не нужно.

## 4. Дождитесь зелёной галочки (2 мин)
Вкладка **Actions** → «Deploy to GitHub Pages» → зелёная галочка. Сайт: `https://ЛОГИН.github.io/motivaciya/`.
Никакие переменные окружения/секреты не нужны.

## 5. Подключите Google Таблицу (5 мин)
См. `google-apps-script/README.md`. Затем в файле `src/lib/appConfig.ts` укажите `gasUrl` и сделайте push:
```
git add -A && git commit -m "gasUrl" && git push
```
Через 1–2 минуты сайт обновится у всех.

## Пароли из коробки
- Продавцы: `1234` (Центральный, Северный, Западный, Южный, Восточный, Дисконт), `5678` (Заречный, Премиум)
- Админ: `admin123` (меняется в `src/lib/appConfig.ts`)

## Если что-то пошло не так
| Симптом | Что сделать |
|---|---|
| Actions красный | Откройте лог шага. Чаще всего — опечатка в `appConfig.ts`. |
| Сайт 404 | Проверьте Settings → Pages → Source = GitHub Actions; подождите 2 мин. |
| Правки «воскресают» | Скрипт в таблице устарел: Админ → Синхронизация → «Проверить скрипт». Вставьте новый код и опубликуйте **Новую версию**. |
