# Онлайн за 5 минут: Google Таблица + Apps Script

Таблица — единственный источник правды. Скрипт `MotivaciyaBackend.gs` (один файл, ES5) даёт приложению чтение и запись.

## Шаги
1. Создайте новую Google Таблицу (sheets.new).
2. **Расширения → Apps Script**. Удалите всё в редакторе, вставьте содержимое `MotivaciyaBackend.gs`
   (или в приложении: Админ → Синхронизация → «Копировать скрипт (с данными)» — тогда в таблицу попадут ваши текущие данные).
3. Сохраните (Ctrl+S). Вверху выберите функцию **setupMotivaciya** → **▶ Выполнить**. Разрешите доступ (Дополнительно → Перейти).
   В таблице появятся 5 листов с жёлтыми шапками: `Товары`, `Магазины`, `Акции`, `Категории`, `Настройки`.
4. **Развернуть → Новое развёртывание → ⚙ Веб-приложение**:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   → **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
5. Вставьте URL в `src/lib/appConfig.ts` → `gasUrl` (и `dataSource: 'gas'`), сделайте push. Готово.

Проверка: откройте `URL/exec?action=ping` в браузере — должно быть `{"status":"ok","gasVersion":7,…}`.

## ВАЖНО: после любой правки кода
**Развернуть → Управление развёртываниями → ✎ → Версия: Новая версия → Развернуть.**
Без этого по старому URL продолжает работать старый код (приложение покажет «скрипт устарел»).

## Что нового в v7 (обязательно обновить, если видели «Тайм-аут блокировки»)
- Пишутся только изменённые листы; `autoResizeColumn` выполняется только в `setupMotivaciya()`.
- Запись идёт поверх старых значений с очисткой хвоста — лист не бывает пустым даже на миг.
- Чтение (`doGet`) идёт под той же блокировкой — читатель не увидит наполовину записанный лист.
- Если таблица занята дольше 20 с — ответ `{status:'error', code:'busy'}`; приложение повторит само.
- `saveData` отклоняет пустой payload (0 товаров и 0 магазинов), чтобы случайно не стереть таблицу.
- В ответе `saveId` (эхо запроса), `written` (какие листы переписаны) и `ms`.

## API
- `GET …/exec` → все данные (JSON `AppData`, поле `gasVersion`)
- `GET …/exec?action=shops` → `[{name, group}]`
- `GET …/exec?action=ping` → `{status:'ok', gasVersion, time}`
- `POST …/exec` (text/plain, JSON) `{action:'saveData', saveId, data}` → `{status:'ok', gasVersion, saveId, counts, written, ms}` или `{status:'error', code:'busy'|'unknown'|'', error}`
- `POST …/exec` `{action:'sendReport', to, subject, htmlBody}` → письмо через MailApp

## Правила листов
- Пустые строки пропускаются. Первая строка — шапка.
- `Товары`: Магазины через запятую (пусто = все). Колонки Базовый/Стандартный/Высокий — градации `869|27,5;782-868|22,5` (пусто = товара нет в этом прайсе). Красный — `да`. Статус `активен`/`выключен`.
- `Магазины`: Прайс-группа `Базовый`/`Стандартный`/`Высокий` — какую колонку цен видит магазин. `Доп.условия` — до 10 плашек `Название|Значение|иконка|цвет` через `;` (иконка/цвет можно не указывать). Старые колонки «Доп.1 название/значение…» читаются автоматически.
- `Акции`: `Цена`/`Бонус` — первая ступень, `Градации` — все ступени `799|40;750-798|32;до 749|25` (если пусто, берутся Цена/Бонус).
- Все ячейки пишутся как текст (`@`), чтобы `782-868` и даты не превращались в числа/даты.

## Переход со старой таблицы (10 листов)
Скрипт v4 распознаёт старую раскладку (колонка «Градации» в `Товары`) и отдаёт её приложению, которое само собирает новый формат. После первого сохранения лист `Товары` перепишется, а `Прайс_*`, `Привязка_прайсов`, `Цены_по_группам` можно удалить.
